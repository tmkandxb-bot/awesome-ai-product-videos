# Case: deals-post-writer

**Skill:** `deals-post-writer` (free) — turn one verified deal into a deal post, an interactive post, and a Reels script.

**Input → Output**
- **Input** (`input.md`): a real, dated Walmart Flash deal — the Walsunny Tall Storage Cabinet at $75 (was $144), reported by TheStreet on Oct 31, 2026, with the cabinet's real dimensions and material.
- **Process:** the deal was run through the skill's three formulas. The discount math was re-checked before writing ($144 → $75 = 47.9% ≈ 48% ✓). No end date existed in the source, so the post claims none. The CTA is a linkless search term, so the post spends zero of a Facebook page's monthly link quota.
- **Output** (`output.md`): one copy-ready deal post, one link-free interactive post, and a 15–30s Reels script with hook, voiceover, on-screen text, and cover text — plus the verification note the skill requires.

**What this case proves:** the skill's price discipline is the product — sourced numbers only, math re-checked, no invented expiry, and a hard rule that a human confirms the price at the store before publishing (deal prices move; this example is a snapshot of the Oct 31, 2026 run, not a live offer).
